
# 👾 Reel Monster

Your tiny scrolling buddy!

Reel Monster is an Android application designed to help users track their reel scrolling habits, count reels, estimate time spent, and encourage healthy screen-time habits.

## Features
- Manual reel counter
- Floating monster overlay
- Accessibility-based scroll tracking
- Daily reel count
- Estimated time spent scrolling
- Screen-time awareness

## How to Use
1. Install Reel Monster on your Android phone.
2. Open the application.
3. Tap COUNT +1 to count reels manually.
4. Enable Accessibility for automatic scroll-event tracking.
5. Start the floating monster to use the counter while browsing.
